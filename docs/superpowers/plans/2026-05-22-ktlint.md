# ktlint Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate ktlint via the gantsign Maven plugin so `./mvnw verify` enforces Kotlin code style and `./mvnw ktlint:format` auto-fixes violations.

**Architecture:** Add `ktlint-maven-plugin` to pom.xml with `check` bound to the `verify` phase. Add `.editorconfig` for rule configuration. Fix the two wildcard imports in `FileResource.kt` that ktlint cannot auto-fix, then run `ktlint:format` to clean up any remaining style issues.

**Tech Stack:** `com.github.gantsign.maven:ktlint-maven-plugin:3.5.0`, ktlint standard ruleset, `.editorconfig`

### Task 2: Add `ktlint-maven-plugin` to `pom.xml`

**Files:**
- Modify: `pom.xml` (inside `<build><plugins>`, after the existing `maven-failsafe-plugin` block, before `</plugins>`)

- [ ] **Step 1: Add the plugin to `pom.xml`**

Insert the following block immediately before the closing `</plugins>` tag (line 167):

```xml
      <plugin>
        <groupId>com.github.gantsign.maven</groupId>
        <artifactId>ktlint-maven-plugin</artifactId>
        <version>3.5.0</version>
        <executions>
          <execution>
            <id>check</id>
            <goals>
              <goal>check</goal>
            </goals>
          </execution>
        </executions>
      </plugin>
```

- [ ] **Step 2: Verify the plugin resolves**

```bash
./mvnw ktlint:help
```

Expected: Maven prints help output for the ktlint plugin goals (check, format, etc.).

- [ ] **Step 3: Commit**

```bash
git add pom.xml
git commit -m "chore: add ktlint-maven-plugin"
```
